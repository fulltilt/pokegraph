-when initializing useState with prop variables, it isn't enough just to pass it into useState. You have to initialize it through the 
set variable in useEffect

function MyComponent(props) {
  const [stateValue, setStateValue] = useState(props.initialValue);

  useEffect(() => {
    setStateValue(props.initialValue);
  }, [props.initialValue]); // Only re-run if props.initialValue changes
...
}

You need useEffect to keep your state in sync with the prop because the initial value you pass to useState is only used on the initial render.
