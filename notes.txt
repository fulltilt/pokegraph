# removing outliers (for eBay data)
To remove rows with outlier price values from your SealedPriceEntry table, you need to define what qualifies as an outlier. A common statistical method is to use the Interquartile Range (IQR) or Z-score.

Here’s how to do it using IQR in SQL (assuming you're using PostgreSQL):

✅ Option 1: Use IQR to detect and delete outliers
WITH price_stats AS (
  SELECT
    PERCENTILE_CONT(0.25) WITHIN GROUP (ORDER BY price) AS q1,
    PERCENTILE_CONT(0.75) WITHIN GROUP (ORDER BY price) AS q3
  FROM "SealedPriceEntry"
),
outliers AS (
  SELECT spe.*
  FROM "SealedPriceEntry" spe, price_stats
  WHERE spe.price < (q1 - 1.5 * (q3 - q1))
     OR spe.price > (q3 + 1.5 * (q3 - q1))
)
DELETE FROM "SealedPriceEntry"
WHERE id IN (SELECT id FROM outliers);

✅ Option 2: Use Z-score (e.g., remove rows with z-score > 3 or < -3)
This is more appropriate if your data is normally distributed:

WITH stats AS (
  SELECT
    AVG(price) AS mean,
    STDDEV(price) AS stddev
  FROM "SealedPriceEntry"
),
outliers AS (
  SELECT spe.*
  FROM "SealedPriceEntry" spe, stats
  WHERE ABS(price - mean) / NULLIF(stddev, 0) > 3
)
DELETE FROM "SealedPriceEntry"
WHERE id IN (SELECT id FROM outliers);

## Complete Workflow: Local Development → K8s Deployment

### Step 1: Export Database from K8s VPS

```bash
# SSH into your K8s VPS
ssh ddoria@5.78.146.145

# Export the database from the postgres pod
kubectl exec -n pokemon-app postgres-0 -- pg_dump -U postgres -d pokedex > ~/pokedex_export_$(date +%Y%m%d).sql

# Download to your local machine
# (run this from your LOCAL machine in a new terminal)
scp ddoria@5.78.146.145:~/pokedex_export_*.sql ~/Downloads/

# Or if you want custom format (better for large databases)
kubectl exec -n pokemon-app postgres-0 -- pg_dump -U postgres -d pokedex -F c > ~/pokedex_export.dump
scp ddoria@5.78.146.145:~/pokedex_export.dump ~/Downloads/
```

### Step 2: Import into Local Database

**If using Docker Compose locally:**

```bash
# Start your local environment
cd ~/path/to/your/project
docker-compose up -d

# Import the SQL dump
docker exec -i pokedb psql -U postgres -d pokedex < ~/Downloads/pokedex_export_*.sql

# Or if using custom format
docker cp ~/Downloads/pokedex_export.dump pokedb:/tmp/
docker exec pokedb pg_restore -U postgres -d pokedex --clean /tmp/pokedex_export.dump
```

**If using local PostgreSQL (not Docker):**

```bash
psql -U postgres -d pokedex < ~/Downloads/pokedex_export_*.sql
```

### Step 3: Develop and Test Locally

```bash
# Work on your project locally with your favorite editor
code .

# Make changes to scripts, backend, frontend, etc.
# Test everything locally
bun run scripts/scrape.ts
bun run dev

# Commit your changes
git add .
git commit -m "Updated scraping logic"
git push
```

### Step 4: Export Database from Local (After Changes)

If you made data changes locally that you want to push to K8s:

```bash
# Export from local Docker Compose
docker exec pokedb pg_dump -U postgres -d pokedex > ~/pokedex_local_$(date +%Y%m%d).sql

# Or custom format
docker exec pokedb pg_dump -U postgres -d pokedex -F c -f /tmp/backup.dump
docker cp pokedb:/tmp/backup.dump ~/pokedex_local.dump
```

### Step 5: Build and Push New Images

```bash
# Build updated images
docker build -t ghcr.io/fulltilt/pokemon-backend:latest -f backend/Dockerfile .
docker build -t ghcr.io/fulltilt/pokemon-frontend:latest -f frontend/Dockerfile .

# Push to registry
docker push ghcr.io/fulltilt/pokemon-backend:latest
docker push ghcr.io/fulltilt/pokemon-frontend:latest
```

### Step 6: Import Database to K8s (If Needed)

```bash
# Upload the dump to VPS
scp ~/pokedex_local.sql ddoria@5.78.146.145:~/

# SSH to VPS
ssh ddoria@5.78.146.145

# Copy into the postgres pod
kubectl cp ~/pokedex_local.sql pokemon-app/postgres-0:/tmp/

# Import into the database
kubectl exec -n pokemon-app postgres-0 -- psql -U postgres -d pokedex -f /tmp/pokedex_local.sql

# Clean up
kubectl exec -n pokemon-app postgres-0 -- rm /tmp/pokedex_local.sql
rm ~/pokedex_local.sql
```

### Step 7: Deploy Updated Code to K8s

```bash
# On VPS (or via SSH)
kubectl rollout restart deployment/backend -n pokemon-app
kubectl rollout restart deployment/frontend -n pokemon-app

# Watch the deployment
kubectl get pods -n pokemon-app -w

# Check logs
kubectl logs -n pokemon-app -l app=backend --tail=50
```

### Create `scripts/sync-db-from-k8s.sh` (Local)

```bash
#!/bin/bash
# Download database from K8s to local

echo "Exporting from K8s..."
```

### Create `scripts/sync-db-to-k8s.sh` (Local)

```bash
#!/bin/bash
# Upload local database to K8s

set -e

echo "Exporting local database..."
docker exec pokedb pg_dump -U postgres -d pokedex > /tmp/local_export.sql

echo "Uploading to VPS..."
scp /tmp/local_export.sql ddoria@5.78.146.145:~/
scp -i ~/.ssh/hetzner_id_ed25519 pokedex-data2.sql ddoria@5.78.146.145:/tmp/

echo "Importing to K8s..."
ssh ddoria@5.78.146.145 "
  kubectl cp ~/local_export.sql pokemon-app/postgres-0:/tmp/ &&
  kubectl exec -n pokemon-app postgres-0 -- psql -U postgres -d pokedex -f /tmp/local_export.sql &&
  kubectl exec -n pokemon-app postgres-0 -- rm /tmp/local_export.sql &&
  rm ~/local_export.sql

echo "Done! K8s database synced with local."
rm /tmp/local_export.sql
```
